# 不烧心小馆（重制版 V3 · 自由地图）

柳河街上一间十平米的早餐铺，短租二十八天。你整个早晨都站在柜台后面：粥要搅、油条要翻、豆浆接到刻线，客人拿着票据等着，门外还排着队。招牌是空的——月底写上去什么字，看你这个月怎么做生意。

浏览器可从开店玩到第 28 天结局（八个结局）。一天是：开门前 → 晨备 → 早市 → 收摊 → **下午出门**（第 3 天起：批发市场验货、7 路总站接包餐、去熟客那里串门、桥头听明天的天气、回店练手）→ 晚账。目标平台仍是微信小游戏，微信端入口已生成但**未在开发者工具和真机上验证**。

然后打开 http://127.0.0.1:4173 。无需安装依赖。本机终端里没有 `node` 命令时用上面的绝对路径。`?dev` 显示帧率和隐藏读数，`?safe=wechat` 模拟微信胶囊与安全区。

## 怎么玩

- **点**：顺手做——盛粥、下锅、翻面、出锅并递给最急的那位。
- **拖**：把做好的东西拖给指定的客人，或先搁在出餐台，或拖到台角的桶里倒掉。
- **按住**：接豆浆（到刻线松手）、磨豆、拉卷帘门。
- 常客头顶冒"…"时点一下，他有话说。票据上只写"老样子"时，凭记性做；记不得就点票据问一句。
- `P` / `Esc` 暂停，`F` 全屏，`Tab` + 回车可用键盘操作界面。

## 目录

- `src/` 源码，结构见 `docs/DESIGN.md` §8；`docs/CONTENT_SPEC.md` 是内容格式与人物圣经。
- `assets/runtime/` 运行时图片（约 7.5MB）。
- `legacy/v1-2026-11-05/` 重制前的完整实现（源码、测试、工具、文档），原样保留。
- `output/e2e/` 自动回放的截图与日志；`output/v2/` 开发过程中的检查截图。

## 已知限制

- 手感、难度和后期客流只经过机器人回放和模拟校准，**没有真人试玩数据**。
- 声音全部是程序合成，没有人听过成品；见 `HUMAN_TASKS.md`。
- 手机上逻辑画布按高度缩放，小屏（高度 < 400 CSS 像素）文字偏小。
- 微信端未验证；图片素材的对外发布许可仍待核对。
