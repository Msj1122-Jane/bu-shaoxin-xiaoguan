# 《不烧心小馆》首版视觉资产分层规格 V0.1

状态：已授权制作首版；本规格用于 Lovart 出图和游戏接入。

## 核心画面目标

玩家在横屏早餐铺中一眼看见顾客订单和三处可操作厨具。做饭区比装饰更醒目，画面温暖但不能因黄色过多而失去交互对比。

## 层级

| 层级 | 资产 | 能否交互 | 规则 |
| --- | --- | --- | --- |
| L0 | 室内墙面、门窗、远景街道、固定货架 | 否 | 不含人物、食物、文字、订单或可点击厨具 |
| L1 | 木柜台、地面、桌椅等固定中景 | 否 | 中央和下方为厨具与手势保留清楚轮廓区 |
| L2 | 粥锅、油锅、豆浆壶及各自台座 | 是 | 独立透明 PNG；视觉轮廓不同；可放大为至少 96dp 热区 |
| L3 | 顾客人物、老板、托盘、食物成品 | 是／动态 | 人物不能烘焙进背景；成品能单独移动到托盘 |
| L4 | 蒸汽、油泡、液流、亮点、缺料符号 | 反馈 | 小范围、短时、可关闭；不靠颜色单独传达状态 |
| L5 | 订单泡、耐心环、铜钱、日历、暂停 | UI | 不烘焙文字；图标轮廓清楚；全部在 90% 安全区内 |

## 首批必须交付

1. `scene_background`：16:9 早餐铺室内，无人物、无前景厨具、无 UI。
2. `scene_counter_foreground`：木柜台与前景遮挡，可透明叠加。
3. `station_porridge`：白粥锅与木勺。
4. `station_fryer`：油锅、面坯与漏勺。
5. `station_soymilk`：豆浆壶与杯／碗。
6. `order_icons`：白粥、油条、豆浆三个订单图标。
7. `feedback_fx`：蒸汽、油泡、液流／泡沫三组反馈图形。

## 出图限制

- 暖色叙事型 HD 像素画，与已确认视觉方案一致。
- 正面或轻微俯视，避免强透视导致触控位置难判断。
- 不出现英文、汉字、假字、水印、logo、价格或按钮文字。
- 不把角色、订单、厨具和特效画死在同一张背景里。
- 图标不能只用颜色区分；白粥为碗形、油条为长条形、豆浆为杯／壶形。
- 主要互动轮廓在 720p 横屏缩小时仍可辨认。
