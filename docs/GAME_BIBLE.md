# 游戏圣经（GAME_BIBLE）

本文件是制作期间不可改变的核心与已确认设计的浓缩版。完整设计见 `../../不烧心小馆-完整游戏策划书GDD-V1.1.md`。冲突时以 GDD 为准，此处记录的是"做游戏时随时要对照的那一页"。

## 一句话
玩家经营一家当代江南社区早餐铺，每天开门前决定油、料、价格和菜单，营业中亲手做出一份份早餐，月底面对自己赚到的钱、留下的人和做过的选择。

## 不可改变
1. 28 个营业日、老周、油/料/价三项决策 + 菜单、亲手完成代表性订单。
2. 做饭是最好玩的环节：画圈、拖拽、按住/倾倒、滑动/拉伸、时机火候，食物形态变化 + 多层反馈，允许补救。
3. 剧情发生在会呼吸的店里：顾客、天气、菜品、价格、经营结果、常客是否出现都参与叙事。
4. 主画面以场景、器具、食物、图案与动效为主，文字退到对白、账本、设置；器具本身就是入口。
5. 画风：当代江南社区早餐铺、暖色叙事型 HD 像素画。青绿 + 木色 + 米白；红色只做少量风险锚点。
6. 没有简单善恶答案；便宜、冻品、散装、添加剂不写成违法/有毒；烧心不是医学诊断。
7. 无内购、无抽卡、无强制广告、无体力、无运行时大模型。
8. 长期动力：手艺熟练、人物关系、剧情悬念、菜谱发现、小馆痕迹、不同结局、继承重开与常营业。

## 禁止
文字选择器/PPT 式界面；抄商业游戏界面与素材；开放世界/多人/PVP/装修/多货币/第二家店；营业画面堆数字与常驻 HUD；不可跳过长视频；空壳内容；未运行就宣称完成。

## 关键数值（首轮，可按试玩调）
- 现金 3000 元起；口碑 50；产能 48 份/日（帮工 +18，工资 30/日；熟练度每 6 星 +2，上限 +10）。
- 客流 = 36 × 价档客流倍率 × (0.45 + 口碑/80) × 常客修正(≤1.2) × 天气/事件 × 随机 0.9–1.1；成交 = min(客流, 产能)。
- 价档：亲民 ×0.85 价 / ×1.30 流 / 口碑 +0.2；合理 1/1/0；劝退 ×1.30 / ×0.65 / −0.2。
- 固定成本 100/日（房租 60 + 水电 40）。
- 烧心：循环用油第 1–2 日 0/+4，第 3 日起 +6，之后每日再 +2，上限 +14；勤换新油 −3/日；增香粉隐瞒 +20–25；储存不当 +15；公示/退款/整改 −10–−60。
- 烧心分层 0–29 / 30–59 / 60–79 / 80–99 / 100 → 危机夜（口碑 −15、现金 −300，三选一）。
- 房东通牒：现金连续两日 <0 → 卖设备 / 街坊短借 300（月底还 360）/ 不借（第三日仍负则结束）。每局一次。
- 品质：招牌 ≥0.88 / 家常 0.60–0.87 / 匆忙 <0.60；熟练度 3/8/15/24/35 次升 1–5 星。
- 顾客耐心 24–34 秒，常客更长；归零前 4 秒补救期；对话/暂停/切后台期间耐心暂停。
- 事件：非固定日 60% 概率；一局约 16–19 张；紧后优先松；营业后事件不回写当日客流。

## 八结局判定顺序
提前结束(口碑≥60 送行 / 否则转让) → 硬撑危机(胃药和账单) → 整改恢复(重新开张) → 精品(私房小馆) → 平价街坊(街坊食堂) → 高口碑透明(贵是贵点) → 其他(月底那天，还是有人来了，分低中高三段)。
