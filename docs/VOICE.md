# 《不烧心小馆》台词重写规范（V3，2026-11-15）

玩家的反馈：**对话生硬、剧情感不强**。原因不在情节（情节骨架保留），在说话的方式：

1. 每句都是电报——"十平米。""嗯。头一天。""行。"——人不这么说话。
2. 老周没有声音。他只会"嗯""行"，玩家不知道他为什么开这家店、怕什么、盼什么。
3. 所有人一个腔调：短、冷、克制。八位常客读起来像同一个人。
4. 每场戏都在"交代一件事"，没有来回、没有打岔、没有玩笑、没有没说完的话。

这次重写**只改文字**，不改结构（见文末"硬约束"）。

## 一、这条街说什么话

柳河街在西南一座临河的老城（不点名）。小面、叶儿粑、醪糟汤圆、糖油果子都是这里的早饭。街坊说的是**带一点川渝味的普通话**：全国玩家都看得懂，但听得出地方。

- 可以用（点到为止，一场戏两三处）：要得、啥子、咋个、莫、晓得、巴适、安逸、娃儿、噻、嘛、哦豁、恼火、将就、耍、摆（聊天）、打望、扎实、一哈、得行、不得行。
- 不要用生僻字和整句方言；不要每句都带语气词。
- 轻重因人而异（见下表）。年轻人接近普通话，老人味道重。

## 三、一场戏怎么写

- **每场戏要有一个"想要"和一个"没说出口"**。汪姐来收租——她想要的是钱，没说出口的是"我其实希望你撑下去"。
- **有来有回**。至少一次打岔、一次答非所问或一句玩笑。不要 A 交代、B "嗯"。
- **老周要回话**。把现在的"嗯。""行。"至少换掉一半：换成一个具体的动作、一句笨拙的实话、或一句岔开的话。保留几个"嗯"当节奏。
- **用物件说感情**（原规范保留）：袖口、硬币、头盔、茶缸。不写"他很难过"。
- **不讲道理**。任何人说出"做生意要讲良心""诚信最重要"这类话都删掉。老胡那句"良心几个钱一斤？"这种反着说的可以留。
- **不要三连排比、不要"不是……而是……"、不要金句收尾**。一场戏停在一个动作或一句没说完的话上。
- 句子可以长一点了：对白每句 **≤ 40 字**（对话框能排两行），多数在 10–30 字。旁白 `n` 每句 ≤ 40 字，每场 ≤ 4 句。一场戏的句数上限放宽到 **18 句**。
- 早市气泡（`say.in/good/ok/bad/slow/out`、`barks`）仍然 **≤ 16 字**，`chat` 每句 **≤ 22 字**——那是忙的时候瞄一眼的东西，但也要像人话、要有各自的腔调。
