## 1. 工具与命令

| 命令 | 作用 |
| --- | --- |
| `node --test tests/*.test.js` | 规则、内容、存档、结局单测 |
| `node tools/validate_content.js` | schema、引用、前置、可达性、八结局互斥与覆盖 |
| `node tools/sim.js [--seeds 20]` | 27 固定组合 + 动态策略 + 多种子平衡扫描，输出 `output/sim/report.md` |
| `node tools/serve.js` + `node tools/e2e/<flow>.cjs` | Playwright 实操回放与截图至 `output/e2e/` |
| `node tools/build_wechat.js` | 微信工程产出与包体检查 |

`node` 不在 PATH 时使用 `/Users/msj/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node`。
