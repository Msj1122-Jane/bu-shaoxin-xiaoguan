# 平衡表（BALANCE）

所有数值在 `src/content/config.js`、`src/content/dishes.js`、`src/content/regulars.js`、`src/content/events.js`。修改后跑 `npm test` 与 `node tools/sim.js`。

| 参数 | 值 | 设计意图 |
| --- | --- | --- |
| startCash | 300000 分 | 3000 元周转：普通选择前 7 日不会见底（测试保证） |
| fixedCost | 10000 分/日 | 房租 60＋水电 40，每天都要卖出约 25 份才保本，营造“今天得忙起来”的底线 |
| baseFlow / baseCapacity | 36 / 48 | 产能略高于基础客流，口碑上去后产能成为瓶颈，自然引出帮工与熟练度 |
| price.mult / flow / rep | [0.85,1,1.25] / [1.3,1,0.62] / [+0.2,0,−0.25] | 亲民多卖薄利涨口碑；劝退少卖但单价高，需熟客与好料支撑 |
| material.cost / rep | [0.8,1,1.42] / [−0.05,0,+0.15] | 冻储省钱略伤口碑；可追溯贵但口碑稳步上升，老秦路线的条件 |
| oil.daily | [12,26,42] 元 | 循环用油省钱；连续使用通过烧心与小宋/小郑反馈付出代价 |
| burnOil | 第 2 日 +4，第 3 日起 +6 每日再 +2，上限 +14；新油 −3 | 一两天没事，连着用才出问题；可通过换油恢复 |
| quality 阈值 | 0.88 / 0.60 | 招牌要认真，家常容易拿到，匆忙也不报废 |
| qualityRep | 招牌 +0.6 / 家常 +0.1 / 匆忙 −0.6（按单占比） | 手艺直接影响口碑，但一单失误影响有限 |
| 常客好感 | 招牌 +0.85 / 家常 +0.6 / 匆忙 +0.3 / 没等到 −0.5 | 一个月平均推进 16/24 段，保留重玩悬念 |
| eventChance | 0.6（开店前 ×0.7、营业后 ×1.0） | 一局约 16 张事件，加主线 7 段 |
| crisis | 口碑 −15、现金 −300；整改 −600 停业一天、烧心降到 60；退款 −400、口碑 −20、烧心 −60、三日后按关系回升；硬撑无代价但每日口碑 −1.2 | 每个选择都有真实代价，没有免费解 |
| rescue | 卖设备 +500 / 借 300 还 360 / 不借 | 每局一次翻盘，防新手无预警出局 |
| renewal.deposit | 120000 分（房东涨租事件 ±20000） | 月底押金是第一章外部压力的具象化 |

## V2 诚信/黑心与爽感参数（D030–D038）

| 参数 | 值 | 设计意图 |
| --- | --- | --- |
| baseFlow / baseCapacity | 54 / 70 | V2 提高客流，早高峰更忙，连击才有舞台 |
| 偷懒捷径 | 每次省 2.5 元，烧心 +0.7，口碑 −0.03 | 当下看得见的小便宜 |
| 吃坏判定 | 基础 6% + 每次捷径 3% + 烧心/350；吃坏退款、口碑 −0.5、烧心 +1 | 偷得越多越容易出事，且是确定性的，不能刷 |
| 连续诚信 | 每日客流 +3%，上限 +15% | 诚信越做越顺 |
| 连击小费 | 每连 +0.5 元，上限 10 连 | 早高峰的爽点 |
| 灯笼档位抽查率 | 明亮/微暗 0，发红 20%，冒烟 35%，封条 50%；罚款 200 元，冷却 4 日 | 越黑心越常被查 |
| 对手黑心店 | 第 4 日开张客流 ×0.85，第 15 日查封后 ×1.3 | 亲眼看到黑心店的下场 |
| 节令日 | 腊八 d10 ×1.15、小年 d17 ×1.25、饺子日 d22 | 月中有盼头 |
| 奇遇 | 55% 概率出现；效果减半 | 防口碑膨胀 |
| 升级 | 100–500 元共 8 项 | 赚的钱有地方花，花了做菜更快 |
