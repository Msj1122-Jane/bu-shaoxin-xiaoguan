# 不烧心小馆 七天切片 0.1

2026-10-29。已做成可玩的浏览器流程原型，正式目标仍为微信小游戏。本版不是完整游戏，也不是可直接提审的发行包。

## 启动

在此目录运行 `node tools/serve.js`，打开 http://127.0.0.1:4173 。无需安装 npm 依赖。

此电脑可用的 Node 路径：`/Users/msj/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node`。终端找不到 node 时，用这个绝对路径替代。

运行测试：`node --test tests/core.test.js`。

预览服务只监听本机，不是线上地址，其他成员手机无法直接访问此链接。关闭服务后需重新启动。

## 已有

- 七个营业日，晨备→控火→营业结算→五张固定事件→晚账→阶段总结。
- 三组档位按钮、四道菜单、整数分记账、逐菜销量成本与收入。
- 一种按住松手的熬粥操作，可选普通火候跳过；当前是全菜单共用的操作样例。
- 赵爷爷与小宋独立好感，事件即时和延迟效果，帮工次日增加产能与工资。
- 主备本地存档、继续与二次确认重开、随机种子复现。
- 共用 core 和 Canvas 界面的浏览器/微信入口。

## 微信入口

`game.js`、`game.json`、`project.config.json` 已提供导入骨架，使用游客占位 AppID。需在微信开发者工具换成自己的小游戏 AppID，并验证基础库/API、图片与触摸、生命周期、存档和真机安全区。本轮未运行微信开发者工具，不声称微信版已验证。项目中不存 AppSecret 或上传密钥。

## 本轮验证

六项 Node 测试通过：七天记账与幂等、事件存档恢复、延迟效果只执行一次、帮工次日生效、确定性重放、坏数据与菜单校验。
